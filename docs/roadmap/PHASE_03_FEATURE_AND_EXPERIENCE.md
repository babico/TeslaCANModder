# Phase 03 - Feature And Experience

## Goal

Improve operator productivity and safety confidence through better controls and feedback loops.

## Planned Work

1. Web frame monitor enhancements:
   - Export CSV/JSON.
   - Saved filter presets.
   - Better visual decoding affordances.
2. Web command usability:
   - Command palette and recent actions.
   - Capability-aware disabled states with reason text.
3. Mobile UX upgrades:
   - BLE device quality labels (RSSI/service hints).
   - Better reconnect and in-flow troubleshooting messages.
4. Docs UX:
   - Setup quickstart checklist.
   - Troubleshooting decision tree.
   - Wiring quick-reference visuals.

## Acceptance Criteria

- Operators can export and share session data in one action.
- Common command paths become discoverable without deep navigation.
- Mobile users recover from disconnect with minimal friction.
- First-time setup completion succeeds with fewer support questions.

## Validation

- UX walkthrough script for top 10 tasks.
- Time-to-task and error-rate comparison against baseline.
