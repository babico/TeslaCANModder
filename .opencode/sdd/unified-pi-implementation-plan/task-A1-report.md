## Interface handed to A2/A3

```ts
export type CanTransport = "vcan" | "socketcan";
export function getCanTransport(env?: NodeJS.ProcessEnv): CanTransport;
export interface PiServerOptions {
    transport?: CanTransport;
    fallback?: RequestListener;
}
export function createPiServer(options?: PiServerOptions): Server;
```

- `GET /health` → `200` + `{"ok":true,"transport":"socketcan"|"vcan"}` (`application/json`).
- Unknown routes → `404` JSON when no fallback; otherwise delegated to `options.fallback`,
  which is the mount point A3 uses for the authenticated command bridge.
- `CAN_TRANSPORT` env: only literal `"vcan"` selects `vcan`; anything else → `socketcan`.
  No CAN TX code, no Sentry code, no credential handling in this task.
